The glossary

Every defined term in the book and the record, in one alphabet — each sense quoted from the page that defines it, and linked back there

This page gathers the book's glossary (62 terms) and every glossary on the shelf (20 pages) into one list. Nothing here is newly defined: each sense is quoted from its page, with that page named beside it — teal for the book, gold for the record, with the session that filed it. Where a term is defined in more than one place, every distinct sense stands, the book's first; where two pages say the same thing, it appears once. A disagreement between senses is information, not an error to be smoothed here — the book states; the record collects.

A

A, B, C — the juxtaposed reading
Five disjoint regions tile the rectangle: A = O L M, D = O M X, B = M X N, D = X N R, and C = O X R (hatched), each letter on its own ground. The diagonal O–N halves the rectangle into A + D + B above and C + D below; cancel D = D and A + B = C holds with nothing counted twice. The overlap lives only in the interpretation, where B and C stand for the classical base-b and base-c triangles under an apex — readings the check file verifies agree with this one.
